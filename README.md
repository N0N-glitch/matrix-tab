# Matrix Tab

ENGLISH

> Transform your New Tab into an interactive hacker terminal with a real-time Matrix code rain animation.

## Features

* Real-time Matrix Rain: Fluid cyberpunk-style character animation in the background.
* Dynamic Clock and Date: Real-time clock with complete date indicator.
* Quick Shortcuts: One-click direct access to developer-friendly sites (GitHub, YouTube, ChatGPT, StackOverflow).
* Interactive Terminal: Built-in command line supporting useful commands.

## Terminal Commands

Type the following commands directly into the extension terminal bar:

* `help` - Shows the complete list of available commands.
* `clear` - Clears the terminal history.
* `open [site]` - Quickly opens a site (e.g., `open github`, `open youtube`, `open google`).
* `echo [text]` - Displays a custom message in the terminal.
* `date` - Shows the exact system date and time.

## How to Install Locally

Since this extension is not yet on the Chrome Web Store, you can install it manually using developer mode in your browser (Chrome, Brave, Edge, or Kiwi Browser on mobile):

1. Download or clone this repository to your device.
2. Open your browser and navigate to the extensions page (`chrome://extensions/`).
3. In the top right corner, enable Developer mode.
4. Click the Load unpacked button.
5. Select the folder where you downloaded the `matrix-tab` project.
6. Open a New Tab and enjoy your new Matrix environment.
